## 运行

在本目录运行 `npm run dev`（需要 Python 3），打开 http://127.0.0.1:8016 。也可以使用任意静态服务器。不能以 `file://` 打开 ES Modules。

`npm test` 使用 Node.js 20+ 自带测试运行器，不需要安装依赖。

## 第一版玩法

- 儿童模式：三个游戏难度，每级 50 个不重复四字成语，共 150 题。分组不等同于教材年级。
- 萌芽、成长各缺一个字；绽放缺两个字，从左到右分别四选一。键盘 1–4 可选择。
- 每轮 8 题，优先出未认识的题，再从已有题目补足；可多轮玩完每级 50 题。
- 首次可选 6 题测验，每级 2 题。前一级两题均无误、未用提示才推荐下一档。测验非诊断性，不锁定难度，可重测或直接选档。
- 测验的“还没学过”展示答案与解释，记为未独立完成。普通练习允许重试与提示。
- 逐题倒计时：萌芽 30 秒、成长 24 秒、绽放 20 秒；双空题共用预算，不因填好第一字重置。最后 5 秒红色警示和提示音。气泡飞行、阅读解释、设置/返回对话框、后台标签页暂停；超时展示答案并进入复习（测验只影响建议、demo 不写记录）。
- 每题结束后手动进入下一题，给儿童读释义与例句的时间。全局完成分固定 100，独立答对题数另列，超时不算独立答对。倒计时参数在模式等级的 `seconds` 中，可独立配置成人模式。
- 使用过提示或答错后完成的题进入复习列表，之后无提示首次答对才移出。首页“已认识”指完成过，不是学习掌握率。
- 五色 Softie SVG 随进度逐步入场，轮流吐气泡，撞击候选字后把正确字送入空格。气泡只用于出招；纸屑、星星、火花、金币、爱心与角色的粒子动效权重保持平衡。
- 丰富动效演出：非线性强度阶梯、112–128 BPM 音乐叠轨、全亮度放射背景、节拍缩放、彩旗/追光/跑马灯、斜切横幅、圆圈→花形→彩虹旋转印章、对数能量滚动/里程碑砸屏、双空题 reach 加码、跳跃巡游。最后一题触发约 3 秒巨型软乎乎与分层烟花，再开放下一步；候选字不随屏幕震动。
- Demo 每档 2 题，故意错一次展示恢复过程，自动经过解释和结算，再回首页。点“结束演示”或按 Escape 可退出；demo 不改变测验、学习、错题、轮数及设置。`?demo` 可直接启动，但浏览器需用户交互后才允许声音。
- 首页“游戏设置”进入独立配置页，可开关音乐、调整音量、开关完整动效和启动演示；首次尊重系统减少动态效果设置。答题页不展示 Logo 或设置入口。
- 游戏顶部使用彩色圆点进度、粗描边计时牌、填对/差一点统计、能量牌和连击徽章。主角在题卡上方；解释区使用完整边框卡片，释义、例句和按钮有独立留白。
- 存档只保存在当前浏览器；无法写入时显示提示，仍可继续游戏。

## 模式扩展：儿童与成人分离

模式是受众，难度是模式内的等级。儿童与成人模式均已开放，各有独立题库、文案、倒计时与存档。成人题目覆盖职场社交、文史典故与进阶哲理。

```text
js/content/children.js  儿童题目、情境、解释、空位
js/modes.js             各模式的题库、难度、规则、文案、主题标识
js/idioms.js            共用选题、选项、测验建议、学习记录规则
js/storage.js           按模式与版本隔离存档
js/main.js              共用界面与游戏流程
js/choreography.js      特效配方、阈值、音乐强度和能量曲线
js/timer.js             独立于模式内容的倒计时规则
js/softie.js            SVG 角色、弹跳、气泡传字
js/audio.js             音乐与音效合成引擎
js/fx.js                Canvas 2D 粒子系统与角色动效
js/bg.js                二维 WebGL 背景及 CSS 降级
js/core.js              帧时钟与补间动画工具
show.css                分级舞台效果与倒计时呈现
```

成人模式通过以下步骤接入；后续受众可沿用同一架构：

1. 新建 `js/content/adult.js`，导出真实、审核过的题目，ID 使用 `adult-…`。每题含 `id / level / word / meaning / context / blanks`；`word` 是四字成语，`context` 恰好一个 `____`，`blanks` 是有序、不重复的 0–3 索引。可选 `distractors` 为每个空格提供审核过的干扰字数组；省略时使用共用形近字与常用字候选。题量、空位位置不写死在游戏流程里。
2. 在 `MODES` 注册 `adult`：独立题库、等级（含每题 `seconds`）、每轮题数、每级测验题数、演示题数、UI 文案和 theme。首页模式选择器会自动列出已注册的模式，切换重新开始会话。
3. 成人视觉调整使用 `body[data-mode="adult"]` 的主题样式覆盖；无需复制页面和动效引擎。可重新编写文案、难度名称、首页标题与提示语，避免仅给儿童版提高题目难度。
4. `softie-idioms:children:v1` 与未来 `softie-idioms:adult:v1` 分开保存。不要为了启用新模式增加旧模式版本号；改变存档结构时才需要设计迁移。
5. 增加真实题库检查、完成一轮与存档切换的浏览器回归。成人正式题库以及测试用的其他受众配置，均使用相同的共用逻辑处理等级、题数、空位和隔离存档。

暂不引入 CMS、账号、通用插件系统、多语言框架或多个题型。若成人模式需要自由输入/整词选择，应明确新增对应判题流程，不能把它冒充现有单字四选一。

## 打卡、每日任务与奖杯

- 两种模式的历史、任务、金锤、学习统计、奖杯与待展示庆祝分别隔离；切换模式会取消前一模式尚未播放的庆祝，并应用当前模式的设置。
- 每日按本地日期和模式加盐生成 3 个不同指标的任务（简单 2 项、挑战 1 项）。11 个任务定义涵盖练习轮数、连击、独立答对、错题复习、独立全对与能量；每种模式可选 10 个定义，空错题库自动排除复习任务。儿童能量挑战为 300，成人为 1,000，可通过最高难度双空题达成。
- 全部任务完成时立即结算 1 把金锤，上限 3 把；重复练习、回首页及刷新不会重复发放。跨日先结算旧存档中已完成的任务，再生成当天任务。
- 本地日期变化后，首页或下一次答题/结算会刷新任务。月历支持翻页、连续天数、历史最高天数与补签；补签日期保持连击，但不增加实际练习天数。
- 点击日历日期可查看当天每轮的模式、关卡、完成分、答对数、独立答对数、差一点次数、最高连击和用时。用时包含练习与阅读解释，排除后台和返回确认暂停；旧记录缺少的总题数或用时不会虚构补齐。
- 完成分仍为 100；独立全对任务和奖杯要求每题首次答对且未使用提示。

| 系列 | 目标 |

## 内容与兼容性边界

题库是逐条编写的首版内容；自动测试验证数量、唯一性、空位、选项、情境与结构，不代替语文教师的适龄性与语义审校。正式给儿童发布前建议逐题复核释义、例句、干扰字和难度，尤其是存在异体用字的成语。题目 ID 不依赖数组顺序，重新排序或调整难度不会串换学习记录；修正文案也应保留原 ID。

角色和飞行气泡为 SVG，粒子基于 Canvas 2D，二维背景基于 WebGL/CSS 降级。不使用 WebGPU、Three.js、3D 模型或实时软体物理。

浏览器尺寸模拟不等同于真机性能与声音验收；iOS Safari、低端 Android 和音频实际听感需要设备测试。
